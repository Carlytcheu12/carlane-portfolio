# Carlane Tcheuffa Njiena — Portfolio

A responsive, recruiter-focused static portfolio. No framework or build step is required.

## Deploy
- GitHub Pages: upload the folder to a repository, then enable Pages from the repository's Settings.
- Netlify/Vercel: drag the folder into their deployment flow, or connect the repository.

## Before publishing
1. Add your latest CV as `cv.pdf` and add a CV button if desired.
2. Replace any project links with the final live URLs.
3. Replace the initials portrait with a professional photo if desired.
4. Confirm LinkedIn and GitHub URLs.
